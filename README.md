# Symphony

Symphony is a experimental Scratch to Rust transpiler. It aims to convert Scratch code to Rust in order to run projects such as rasterizers and rendering engines made in Scratch much faster than through Scratch's VM.

See [menu synchronization notes](MENU_SYNC.md) when changing the in-app navbar or macOS menu.

See [appearance settings notes](APPEARANCE_SETTINGS.md) when changing the search or submenus.

See [popup windows architecture](POPUP_WINDOWS.md) when adding or changing in-app windows, docking, snapping, resizing, popup appearance, or popup tools.
